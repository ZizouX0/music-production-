# Plugin reference — index

owns (scan: 2026-10-12, see `inventory/plugins.txt`). Each entry was
researched against OFFICIAL manufacturer documentation; anything that
could not be confirmed is explicitly marked "(unverified)" — treat
those items as uncertain and never present them as fact.

**Rule for Claude:** consult the matching file before giving
parameter-level advice on any third-party plugin. Prefer these files
over memory. Stock Ableton devices still come first per the
three-option rule in `CLAUDE.md`.

Notable identification corrections vs. plugin binary names: the seven
"*Core" plugins are United Plugins **effects**, not UJAM synths; Comet,
Supermodal and Filtron are Polyverse; Endless Smile, Eternal Return,
Wide Awake and Space In-Your-Face are Dada Life; LOVEND is Analog
Obsession; Mesa Lite is a Venomode clipper; Retromulator is a discoDSP
hardware-synth emulator; Astra is Splice's own synth; LABS now lives
inside Splice INSTRUMENT. **Decapitone remains unidentified** — check
its GUI in Live.
